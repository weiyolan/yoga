How to push it: studio/scripts/content-v2.ts

  • The current seed.ts only fills empty fields (setIfMissing), or overwrites everything with --replace. Neither fits: v2 must replace specific fields and keep the other Studio edits.
  • New one-shot script: patch(id).set({...}) per field from this list, unset for removals (placeholder testimonial, fake schedule slots, principles), create for Rochefort, collaborators and legal pages. Has --dry (prints a diff) like the seed.
  • Writes go to drafts (drafts.<id>), so R&P can review them in the Presentation tool and publish themselves, in line with their draft/publish flow.
  • Reviews import: scripts/import-reviews.ts --file=evaluaties.xlsx → review docs (public), dedup on name+retreat.
  • Run after the schema changes in Part 2 (new fields first), then npm run typegen.
